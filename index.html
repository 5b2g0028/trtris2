關於本專案

本專案是全端網頁程式設計的精華縮影，以經典的 2D 幾何消去遊戲「俄羅斯方塊」為載體，實作了高效的前端 Canvas 二維矩陣渲染與 Wall Kick 碰撞排除演算法，並串接 Express 後端與 MongoDB Atlas 雲端資料庫，建構即時的分數排行上傳與展示。

網頁全端開發學習足跡

本學期網頁技術開發的蜕變歷程

階段一：網頁靜態佈局與樣式美學

Week 1 - 5

熟練 HTML5 語意標籤架構與 CSS3 Flexbox/Grid 響應式佈局。學習 CSS 變數、陰影、漸層色與過渡動畫，打下美觀的 UI 設計基礎。

階段二：JavaScript 核心與 DOM 互動

Week 6 - 9

深入非同步程式設計、ES6+ 語法及 DOM 事件監聽。實作前端互動邏輯，並透過 Canvas API 進行遊戲畫面的二維渲染控制。

階段三：Node.js Express 後端 API 建構

Week 10 - 13

使用 Node.js 與 Express 框架架設 RESTful API 伺服器。定義並校驗 POST/GET 連線，處理 CORS 跨域資源存取，實踐前後端整合。

階段四：NoSQL 資料庫儲存與雲端發布

Week 14 - 18

設定 MongoDB Atlas 雲端資料庫並使用 Mongoose 進行資料映射管理。為專案部署至雲端生產環境，達成具備持久化排行榜的完整全端網頁應用。
